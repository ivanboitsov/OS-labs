# Лабораторная работа №8

## Цель работы
Приобретение практических навыков диагностики работы программного обеспечения.

## Задание
При выполнении лабораторных работ по курсу ОС необходимо продемонстрировать ключевые
системные вызовы, которые в них используются и то, что их использование соответствует
варианту ЛР.
По итогам выполнения всех лабораторных работ отчет по данной ЛР должен содержать краткую
сводку по исследованию написанных программ.

## Средства диагностики
Для ОС Windows:
- Windbg
  - http://windbg.info/doc/1-common-cmds.html
- Sysinternals Suite
  - Handle.exe
  - Procmon.exe
  - Procexp.exe

## Решение

Для диагностики возьмём 1-ую и 2-ую лабораторные работы данного курса и продемонстрируем ключевые системные вызовы, используя вышеперечисленные средства диагностики.

Из первой лабораторной работы

### parent.cpp

1. **CreatePipe**: Создаёт анонимные каналы (pipe) для межпроцессного взаимодействия между родительским и дочерним процессом. В этой программе два канала используются для ввода и вывода.

2. **GetStdHandle**: Получает дескриптор стандартного потока для стандартного вывода ошибок (STD_ERROR_HANDLE), чтобы перенаправить его в дочерний процесс.

3. **CreateProcess**: Создаёт дочерний процесс и запускает `OS_lab1_child.exe`, используя параметры командной строки. Передаёт дескрипторы пайпов как стандартный ввод и вывод для дочернего процесса.

4. **CloseHandle**: Закрывает ненужные дескрипторы процессов и пайпов после их использования. Это важно для освобождения ресурсов.

5. **WriteFile**: Записывает данные (введённые пользователем числа) в пайп для передачи их в дочерний процесс.

### child.cpp

1. **GetStdHandle**: Получает дескриптор стандартного входа (STD_INPUT_HANDLE), который был перенаправлен на пайп, созданный родительским процессом. Используется для чтения данных из родительского процесса.

2. **ReadFile**: Считывает данные из пайпа, поступающие от родительского процесса. В данном случае данные — это числа, введённые пользователем.

Эти системные вызовы реализуют основные функции для создания процесса, межпроцессного взаимодействия через пайпы и управления ресурсами в Windows.

Из второй лабораторной работы

1. **CreateThread** — создаёт поток для выполнения сортировки элементов массива.

2. **CloseHandle** — закрывает дескрипторы потоков, освобождая ресурсы.

3. **WaitForMultipleObjects** — ждёт завершения всех потоков для синхронизации.

4. **CreateMutex** и **ReleaseMutex** — создают и освобождают мьютекс для защиты доступа к массиву.

5. **WaitForSingleObject** — ждёт блокировки мьютекса перед модификацией массива.

6. **std::thread и std::mutex** (во втором варианте) — используют кроссплатформенные потоки и мьютексы из стандартной библиотеки.

7. **condition_variable** — ограничивает количество активных потоков, используя примитивы синхронизации.

## Вывод

Процесс выполнения программы на С++ обычно включает следующие шаги:
1.	Загрузка исполняемого файла в память.
2.	Загрузка динамических библиотек (если они используются).
3.	Инициализация статических переменных.
4.	Выделение памяти для динамических переменных и структур данных.
5.	Выполнение кода программы.
6.	Освобождение выделенных ресурсов и завершение программы.
